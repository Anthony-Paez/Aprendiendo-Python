## 📋 Resumen Día 2

**Aprendimos:** condicionales con `if`/`elif`/`else` para que Python tome decisiones; `==` para comparar (distinto de `=` que guarda); `.lower()` para ignorar mayúsculas/minúsculas (aunque no saca tildes); `\n` para saltos de línea dentro de un texto; ifs anidados (uno dentro de otro); `int()` para convertir texto a número; un adelanto de `try`/`except` para manejar errores cuando el usuario escribe algo inválido; y `or` para aceptar varias respuestas como válidas en una misma condición.

**Código que usamos (versión final del reto del gimnasio):**
```python
Membresía = input("Ingrese el tipo de membresía de gimnasio (Básica, Premium): ")

if Membresía.lower() == "básica" or Membresía.lower() == "basica":
    print("Has seleccionado la membresía Básica. Disfruta de nuestras funciones limitadas.")
elif Membresía.lower() == "premium":
    try:
        Edad = int(input("Ingrese su edad: "))
        if Edad >= 16:
            print("Has seleccionado la membresía Premium. Disfruta de todas nuestras funciones.")
        else:
            print("Lo siento, la membresía Premium está disponible solo para mayores de 18 años.")
    except:
        print("Por favor, ingrese un número válido para la edad.")
else:
    print("Tipo de membresía no reconocido. Por favor, elija 'Básica' o 'Premium'.")
```

**Día 3:** vamos a ver **bucles** (`for` y `while`), que le permiten a Python repetir código varias veces, por ejemplo para que el "portero" siga preguntando hasta que le den una respuesta válida, en vez de cortarse después de un solo intento.

Aprendimos: bucles for (repetición de cantidad exacta, con range() y la variable de control i) y while (repetición hasta que se cumpla una condición); la diferencia clave entre ambos con la analogía de las dos vacas (moldes fijos vs. "hasta que caiga la noche"); el operador != (distinto de); cómo combinar != con and/or correctamente (identificando el error clásico de usar or cuando la lógica pedía and); el patrón de "guardar el resultado del input() de vuelta en la misma variable" para que un while pueda detectar cambios; banderas booleanas (variable = False / True) como alternativa más prolija a comparar contra números; break para cortar un bucle a la fuerza; y a identificar cuándo un while o un if sobra porque nunca llega a repetirse de verdad.
