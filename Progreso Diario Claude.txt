## 📋 Resumen Día 5 — Slicing, `.insert()` y `.sort()`

### 1. Slicing básico

**Analogía:** rebanar un tren de vagones — pides un pedazo, no un solo vagón.

```python
mi_lista[inicio:fin]
```

Regla clave: el número de **fin nunca se incluye**, el slice se detiene justo antes.

```python
personajes = ["Remielle", "Eiden", "Eldreda", "Kael", "Lyra"]
#                 0          1         2         3       4
print(personajes[1:3])  # ['Eiden', 'Eldreda']
```

### 2. Lados vacíos

```python
compra = ["leche", "huevos", "pan", "manzanas", "arroz", "café"]
print(compra[:2])   # ['leche', 'huevos']       -> desde el principio
print(compra[4:])   # ['arroz', 'café']         -> hasta el final
```

### 3. Índices negativos

`-1` es el último vagón, `-2` el penúltimo, etc. El tren **nunca cambia de dirección** — los negativos son solo otra forma de nombrar un vagón, el orden del resultado siempre va de izquierda a derecha.

```python
print(compra[-1])    # 'café'
print(compra[-2])    # 'arroz'  (un solo elemento, sin ':')
print(compra[-3:])   # ['manzanas', 'arroz', 'café']
```

### 4. Mezclando positivos y negativos

```python
Lista = ["Eiden", "Billy", "Anby", "Nicole", "Nekomata", "Wise", "Belle", "Hada"]
print(Lista[2:-2])   # ['Anby', 'Nicole', 'Nekomata', 'Wise']
print(Lista[-5:7])   # ['Nicole', 'Nekomata', 'Wise', 'Belle']
```

### 5. `.insert(indice, elemento)`

**Analogía:** alguien se cuela en la fila del colectivo justo en un lugar exacto — todos desde ahí se corren un puesto hacia índices más altos. El índice es el asiento donde **aterriza** el nuevo elemento (no un espacio "entre" dos vagones).

```python
Lista = ["Eiden", "Billy", "Anby", "Nicole", "Nekomata", "Wise", "Belle", "Hada"]
Lista.insert(2, "Soukaku")
# ["Eiden", "Billy", "Soukaku", "Anby", "Nicole", "Nekomata", "Wise", "Belle", "Hada"]
```

### 6. `.sort()`

**Analogía:** amigos desordenados por altura que se reorganizan solos de menor a mayor (o alfabéticamente si son palabras). Modifica la lista **original**, no crea una nueva. Importante: los índices son "asientos" fijos — lo que cambia con `.sort()` es quién se sienta en cada uno.

```python
numeros = [5, 2, 8, 1, 9]
numeros.sort()
print(numeros)  # [1, 2, 5, 8, 9]
```
